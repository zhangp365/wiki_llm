    蒙特卡洛树搜索 (Monte Carlo Tree Search, MCTS)¶

    定义¶

    MCTS 是一种用于不完全信息和高分支因子博弈决策的启发式搜索算法。它通过随机模拟 + 统计采样来评估局面，不依赖手工设计的评估函数。

    核心问题：为什么需要它？¶

    在棋类博弈中，AI 需要在一棵博弈树上搜索最优走法：

                        空棋盘（根节点）
                   /    |    \
                 /      |      \
              走法A   走法B    走法C
              /  \       |        \
           对手走 ...  对手走    对手走

    每一步棋展开的合法走法越多，搜索空间就越大：

    游戏 每步选择数 一局步数 搜索空间
    井字棋 ~5 9 ~5,478
    国际象棋 ~35 80 10¹²⁰
    围棋 ~250 200 10³⁶⁰
    • 井字棋：搜索空间极小，任何方法都够用
    • 国际象棋：Alpha-Beta 剪枝 + 深度评估函数可以处理
    • 围棋：搜索空间爆炸，Alpha-Beta 完全失效，必须用 MCTS

    四步循环¶

    MCTS 的核心是一个四步循环，每次循环树长大一点：

    1. 选择 (Selection)¶

    从根节点沿最"有潜力"的路径往下走，使用 UCB1 公式 选择子节点：

    UCB1 = 胜率 + C × √(ln 父节点访问次数 / 该节点访问次数)
    • 前半部分（胜率）：已验证的实力 — Exploitation
    • 后半部分（探索项）：未充分探索的节点有加分 — Exploration

    这实现了 Explore-Exploit 平衡：既利用已知好的选择，又探索未知选择。

    两个子节点：
  节点A：访问 20 次，胜率 70% → 胜率高，但已充分探索
  节点B：访问 2 次，胜率 50%  → 胜率低，但探索项大

→ 可能选 B（它还没被充分探索，可能有惊喜）

    2. 扩展 (Expansion)¶

    到达一个未展开过的叶子节点时，创建一个新子节点：

    到达：                  扩展后：
 X | O |              X | O |
   |   |        →        | X |    ← 新增子节点
   |   |              |   |

    不在所有节点上扩展，只在最有潜力的方向生长，避免盲目展开。

    3. 模拟 (Simulation / Rollout)¶

    从新节点开始，双方随机走子直到游戏结束，得到一个胜负结果：

    当前局面：          随机走子过程：        最终结果：
 X | O |           X | O | O          X | O | O
   | X |    →     X | X | O    →     X | X | O
   |   |           O | O | X        O | O | X
                                       我赢了 ✓

    纯 MCTS 中这一步完全随机。在 AlphaGo 中，这一步被神经网络替代。

    4. 回传 (Backpropagation)¶

    把胜负结果沿路径反向更新回去：

                        [访问 21 次, 胜率 71%]  ← 更新
                   /            \
        [访问 8 次, 胜率 62%]  [访问 3 次, 胜率 67%]  ← 更新
              |
        [访问 3 次, 胜率 100%]  ← 刚模拟的节点，赢了 +1

更新规则：访问次数 +1，如果赢了则胜利次数 +1，重新计算胜率

    搜索的宽度和深度¶

    搜索宽度（每步考虑多少走法）¶

    围棋每步有 ~250 个合法走法，不可能全搜。AlphaGo 用策略网络做预筛选：

    250 个合法走法
      ↓ 策略网络打分
筛选出 ~5-10 个高概率走法
      ↓ MCTS 在这 5-10 个中展开搜索

    搜索深度（向前看多远）¶

    搜索深度不均匀，不是每条线都看一样远：

                     根节点
               /   |   \
            很深！  一般深   很浅
             |        |
          继续深     到这就停了
             |
          ...（这条路线有意思，一直搜）
    • 关键变化（双方最优应对）→ 搜得很深，可能 20-30 步
    • 明显差的变化 → 搜几步就放弃，不值得浪费时间
    • 实际由时间预算决定（AlphaGo 正式赛约 2 分钟/步）

    具体参数（AlphaGo 各版本）¶

    AlphaGo Fan AlphaGo Zero AlphaZero
    每步模拟次数 ~1,600 ~1,600 ~800
    搜索宽度 策略网络筛选 ~5-10 策略网络筛选 策略网络筛选
    搜索深度 不均匀，关键路线 20+ 步 类似 类似
    每步用时 ~2 秒 ~2 秒 ~0.4 秒

    为什么不用神经网络直接选？¶

    神经网络给出的是单步判断（"当前局面胜率多少"），但博弈需要多步推演：

    我走最优 → 对手走最优 → 我再走最优 → ... → 真正结果

单看一步：胜率 80%（乐观估计）
搜到底：  胜率 10%（被对手反击打爆）

    三重原因： 1. 对手会反击：只看当前胜率是贪心策略，容易掉坑 2. 单次判断有噪声：多次采样平均才能降低误差 3. 长期 vs 短期：需要向前推演发现隐藏的陷阱

    类比：神经网络是老司机凭直觉判断"这条路看起来不错"，MCTS 是真的开车进去看看前面有没有修路。直觉再准也只看一步，往前多走几步才能发现真相。

    神经网络在 MCTS 中的角色¶

    纯 MCTS（无神经网络）：
  当前局面 → 随机走到终局 → 看谁赢 → 统计
  （模拟慢，随机走子质量差，结果噪声大）

AlphaGo（MCTS + 神经网络）：
  策略网络 → 筛选候选走法（缩窄搜索宽度）
  价值网络 → 替代随机模拟直接预测胜率（提高评估质量）
  （模拟次数少但质量高，用 1,600 次碾压所有人类）

    历史脉络¶

    • 1990s：MCTS 由 Rémi Coulom 等提出
    • 2006：首次应用于围棋程序（Crazy Stone）
    • 2016：AlphaGo 结合 MCTS + 深度学习击败李世石
    • 2017：AlphaGo Zero 从零开始自我博弈训练，纯 MCTS + 神经网络
    • 2018：AlphaZero 统一国际象棋、将棋、围棋，同一套架构
